# Showroom — Paname Dev

Site vitrine des apps de Paname Dev. HTML/CSS/JS sans étape de build, publié par GitHub Pages (`.github/workflows/pages.yml`).

- **Charte commune** : [`CHARTE.md`](CHARTE.md) (identité, contact, copyright, graphisme, état de l'harmonisation).
- **Accueil** : `index.html`. **Pages détaillées** : `apps/<app>/index.html`, générées depuis `data/apps.json` par `python3 scripts/build_pages.py`.
- **Ajouter des captures** : déposer `01.jpg`, `02.jpg`… dans `assets/shots/<app>/`. Elles s'affichent toutes seules (voir la section 9 de la charte).
